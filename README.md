## Welcome to Tide Vault! ##

The object of the game is to unlock the vault (treasure chest)

1) Find the keys
2) unlock the doors
3) find the golden key
4) unlock the chest

Controls:

W,A,S,D control up, down, left right
Enter - press ENTER on the main menu to select an option

P - While in game press P to pause the game
O - while in pause press O to save game, this will save your progress, you are then able to close the window, open it back up and press ENTER on the Load Game option.
T - while playing the game, for debugging purposes and more efficency you can see the current draw time.
ENTER - While approaching the NPC press ENTER to filter through the dialouge.

Every tile, and object was drawn by myself pixel by pixel
The music is a unique song created by myself

Enjoy the Tides Vault Hunter!
